# Clinic Database Management System
---
## Project Overview

This project focuses on designing a relational database for a medical clinic.
The goal is to build a structured system that manages patients, doctors, appointments, medical records and billing, ensuring data integrity and efficiet information retrieval.  

---

## Requirements

The database was built to meet the following funcational requirements:

- **Patients:** Manage  patient profiles (ID, name, birth date, ginder, contect details, address).
- **Doctor:** Trak doctor details (ID, name, berth date, gender, specialty, contect details, address).
- **Appointments:** Manage schebuling with different statuses (pending, confirmed, completed, cancelled, reschebuled, no-show).
- **Medical Record:** Link appointments to diagnoses, prescriptions, and physician nots.
- **Prescriptions:** Trak medications, dosages, frequency, and duration.
- **Billing:** Maintain payment records linked to appointments, including payment methods and amounts.
